# Wistia Carousel Builder — How to use it

A self-serve tool for building on-brand carousels for Instagram and LinkedIn.
No design skills required.

## Quick start

1. Open the tool and click **Start a carousel**.
2. You'll see the builder with one cover slide ready to go.
3. Edit the text on the left, watch the canvas update on the right.
4. Add up to 10 slides total using the **+** button in the slide rail.
5. When you're happy, hit **Export carousel** — you'll get a zip with one
   PNG per slide.

## The three slide types

### Cover
Always slide 01. Two looks:
- **Minimal** — big headline, optional logo, optional image strip.
  Best for text-forward openers.
- **Showcase** — featured image takes half the canvas, headline alongside.
  Best when there's a hero visual.

You can include up to 3 images. In Showcase mode, the first is featured and
the rest are supporting.

### Quote
A pull quote with attribution. Two looks:
- **Light** — soft tinted background, dark quote, accent stripe on the left.
  Editorial feel.
- **Bold** — saturated background with the quote in white. Attention-grabbing.

### Rich text
Eyebrow → headline → body. Two looks:
- **Stacked** — everything top-left aligned. The default.
- **Split** — headline on a colored top half, body on a light bottom half.

## Format

Pick once per carousel:
- **1:1 Square** (1080 × 1080) — Instagram feed, LinkedIn
- **4:5 Portrait** (1080 × 1350) — Instagram feed (more vertical real estate)

Switching mid-edit reflows all slides automatically.

## Color scheme

Every carousel has a **primary** and an **accent** color. Pick once per
carousel for brand consistency. The templates adapt — light primaries
(yellow, grey) get treated differently from saturated ones so things
always read.

## Voice & tone reminders

This tool nudges Wistia voice in the placeholders, but as a reminder:
- **Humble** — no bragging, no superlatives
- **Wholesome** — no swearing, no edgy humor
- **Inclusive** — spell out acronyms first time, no cultural references
- **Positive** — frame things upside-up
- **Playful** — but never forced

Refer to the [Wistia brand guidelines](https://wistia.github.io/brand/) for
the full voice doc.

## Keyboard shortcuts

- **← / →** — navigate between slides (when not typing in a field)

## Tips

- **Long quotes** auto-shrink to fit. If a quote still feels cramped, try
  the Bold variant — it handles long copy more gracefully than Light.
- **Image uploads** are stored in the browser, not on a server. If you
  close the tab before exporting, you lose your work. Export early, export
  often.
- **The first slide** is your cover. Lead with the hook.
- **The last slide** should usually be a CTA or link prompt. Use a Rich
  Text slide with a clear next action.
